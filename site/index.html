COLLECTION DESK

收集工作台

点击每个功能的“搜索小红书”后自行查看帖子及评论。逐条录入评论正文，不能用帖子显示的评论总量替代分类数量。评论的功能需结合其所属帖子上下文确认。

批量导入与数据备份

导入 JSON 数组或本网站导出的备份。所有导入记录均进入待复核；相同类型 + 原文 ID 去重，评论 ID 在所属帖子内去重。点击模板查看字段说明。

关闭后仅在当前页面内存中处理，刷新即丢失，请先导出备份。开启后使用 localStorage，仅当前浏览器可见；GitHub Pages 不提供账户、服务器采集或跨设备同步。网站不会上传原声。
